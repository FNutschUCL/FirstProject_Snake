# Your final project

This is the last thing you'll do, and it's the one that earns the
certificate. Unlike everything before it, there are **no prompt cards and
no instructions** — just a brief. That's the point: it's how you find out
what you can do on your own.

## Pick one

**`game/`** — build Tetris from nothing.

**`dashboard/`** — build a personal dashboard, goal tracker, or whatever
version of "the page I want open every day" makes sense for you.

Open the folder you chose and read `BRIEF.md`. Then start a new
conversation with Cline and begin.

Both routes have the **same three requirements**, so neither is easier.
Choose the one you'd actually want to exist.

## Where to work

Whichever you pick, tell the assistant to put the files **inside that
folder**. Something like:

> Work in the folder final-project/game and create the files there.

That keeps your project tidy and separate from the Snake game.
