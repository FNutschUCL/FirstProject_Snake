# Your first project 🐍

**Your lessons should open automatically**, in a panel on the right, with
your game beside it.

Nothing happening? Press `F1`, type **Course: Open lessons**, and hit enter.

That's all you need to know. Go.

---

### What is this?

A small Snake game, and a short course that teaches you to change it by
describing what you want to an AI assistant. No coding required.

Nothing you do here can break anything permanently, and this copy is yours
alone. If something goes wrong, ask the assistant to undo it.

---

*Starter project for a course teaching non-technical people to build with
AI. Runs in GitHub Codespaces with no installation. Built at the UCL
Interaction Centre.*
